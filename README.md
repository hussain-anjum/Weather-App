# Weather Application

A simple and responsive weather application that allows users to check current weather conditions for cities worldwide. This project was built to demonstrate DOM manipulation and API integration using vanilla JavaScript.

## Features

- **Real-time Weather Data:** Fetches up-to-date information including temperature, humidity, and wind speed.
- **City Search:** Users can input any city name to retrieve specific weather details.
- **Dynamic UI:** The interface updates instantly based on the data received.
- **Responsive Design:** Clean and simple interface styled with CSS.

## Technologies Used

- **HTML:** For structuring the web page.
- **CSS:** For styling and layout.
- **JavaScript:** For fetching data from the API and manipulating the DOM.
- **OpenWeatherMap API:** The source for weather data.
